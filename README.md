# Youssef Portfolio

This folder is ready to upload to a GitHub repository and deploy with GitHub Pages.

## Structure
- `index.html` — main website
- `assets/images/` — extracted images
- `assets/pdf/cv.pdf` — extracted CV, if present

## GitHub Pages
Create a repository, upload all files/folders from this directory, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
