# Youssef Hatem — Portfolio

موقع بورتفوليو ثابت (HTML/CSS/JS فقط) — من غير أي build.

## النشر على GitHub Pages
1. ارفع كل محتويات المجلد (index.html + assets + .nojekyll) على ريبو جديد.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. الموقع هيشتغل على `https://USERNAME.github.io/REPO/` خلال دقيقة أو اتنين.

## الهيكل
- `index.html` — الموقع كله
- `assets/` — الصور والسيرة الذاتية (PDF)
