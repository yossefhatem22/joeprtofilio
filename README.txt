GitHub Pages website package

Upload index.html and the complete assets/ folder to the ROOT of your GitHub repository. Keep the folder name exactly as assets.

The images and the embedded PDF have been extracted into assets/. The page has four YouTube iframe embeds; these remain online embeds (not downloadable MP4 files). They require internet access and the YouTube owners must allow embedding.

To update an existing repository: upload/replace index.html, then upload the assets/ folder and its contents. Commit the changes. Do not upload the ZIP itself as the website.
