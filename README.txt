# Website files for GitHub Pages

- Upload `index.html` and the `assets/` folder to the root of your GitHub repository.
- The embedded images have been extracted into `assets/`.
- The four video players are YouTube embeds, not local video files. They need an internet connection and the corresponding YouTube videos must be public/embeddable.
- After uploading, open **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
